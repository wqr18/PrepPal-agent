# PrepPal 智能备课 · 微信小程序

面向高校教师的 AI 备课小程序。核心闭环：**登录 → 创建课程 → 上传教学资料 → 填写教学信息 → AI 生成带来源说明的教案草稿 → 编辑并定稿 → 在课程下管理教案**。

本目录包含两部分：

- **可运行的微信小程序**（`app.js` / `pages/` / `components/` / `utils/` / `config/` / `custom-tab-bar/`）—— 本文档主体
- **原型设计稿** `preppal-prototype.html`（单文件高保真可点击原型）—— 小程序已 1:1 落地其页面、状态与交互；该文件保留作为视觉与文案基线，说明见文末「原型设计稿」

---

## 1. 运行方式

1. 用**微信开发者工具**打开 `preppal-miniprogram/` 目录（appid 已在 `project.config.json` 中配置，勿改）。
2. 先启动后端（当前 `USE_MOCK = false`，小程序默认直连真实接口）：

```bash
cd PrepPal && mvnw.cmd spring-boot:run     # Windows
cd PrepPal && ./mvnw spring-boot:run       # macOS / Linux
```

3. 后端未就绪、只想看页面交互时，把 `config/index.js` 的 `USE_MOCK` 改回 `true`，即可**不启动后端**跑通全部页面与交互。

> `project.private.config.json` 已开启 `urlCheck: false`，开发阶段可直接请求 `http://localhost:8080`，无需配置合法域名。

## 4. mock 与真实后端切换

全部数据访问都经过 `utils/api.js`，其内部按 `config.USE_MOCK` 分流：

| 配置 | 当前值 | 作用 |
|---|---|---|
| `ENV` | `dev` | 决定 `BASE_URL`（`dev` → `http://localhost:8080`） |
| `USE_MOCK` | `false` | `false` 请求真实后端；`true` 走 `utils/mock/db.js` 本地模拟器 |
| `DEV_MOCK_LOGIN` | `true` | `true` 登录提交 `code=mock`，跳过真实微信授权；最终验收改 `false` 走真实 `wx.login`（须用真实 appid，非游客模式） |
| `DEBUG_PANEL` | `true` | 是否在「我的」页展示开发者调试面板（正式交付可置 `false` 隐藏） |

关键设计：**mock 层按后端 wire 格式存储数据**（`objectives` 为单段文本、`teachingProcess` / `sourceReferences` 为 JSON 字符串），并在 `api.js` 边界统一经 `mapper` 转换成展示结构。因此切换 `USE_MOCK` 时，页面代码与数据形状**完全不需要改动**。

> 当前 `USE_MOCK` 已置 `false`，小程序默认走真实后端；mock 层只作为后端未就绪时的回退方案保留。

接口契约与字段映射细节见 `AI-CONTEXT.md` 第 5 节「小程序前端实现」。

## 6. 与原型的设计差异（平台限制导致的替换）

| 原型做法 | 小程序限制 | 本项目方案 |
|---|---|---|
| 内联 `<svg>` 图标 | 不支持 `<svg>` | `pp-icon` 组件映射到 Vant 图标字体，映射表集中在一个文件，图标名不对只需改一处 |
| `contenteditable` 点哪改哪 | 无 DOM | 教案详情页「编辑模式」开关：进入编辑态后各区块换成 `input` / `textarea`，底部「保存草稿」/「标记为定稿」 |
| 拖拽上传区 | 无拖拽事件 | mock 模式提供示例文件列表；真实模式调起 `wx.chooseMessageFile` 选择聊天文件 |
| 自定义 `<div>` 弹窗 / 动作面板 | 无 DOM | `van-dialog`（确认类，支持「标记为定稿」等超过 4 字的按钮文案）、`van-action-sheet`（更多操作 / 切换课程）、`van-popup`（引用原文摘要） |
| 原生 `prompt()` 改课程名 | 无 `prompt` | 复用 `pages/course-edit` 作为编辑页 |
| 侧边栏「演示开关」 | — | 收进「我的 → 开发者调试」，由 `config.DEBUG_PANEL` 控制显隐 |

## 7. 状态覆盖

- **空状态**：首页无课程、课程列表无课程、课程详情无资料 / 无教案、资料列表无资料、教案列表无教案（含筛选后为空）。
- **加载状态**：登录中（按钮内 spinner 且防重复点击）、上传进度条（百分比 + 「上传完成，正在解析内容…」文案切换）、资料「解析中」2 秒后自动转「解析成功」并 Toast、生成中（进度条 + 三步状态清单）。
- **失败状态**：资料解析失败（展示后端返回的编码原因 + 查看原因 / 重新上传）、文件超 5MB 拦截、生成超时失败（重新生成 / 返回修改，保留已填写的教学信息）。
- **确认类**：删除课程、删除资料、删除教案、标记为定稿（文案「定稿后仍可再次编辑，确定标记为定稿吗？」）。
- **校验类**：课程名 2–24 字；教学主题 / 授课对象必填；课时长 10–180 整数、非数字拦截；字段级红色提示 + Toast + 自动滚动到首个错误字段。
- **可信度提示**：有可用资料时显示绿色「已有 N 份资料可用于引用」；未引用到资料时显示黄色「以下内容基于通用知识生成，未参考上传资料」，参考资料区标签同步切换为「通用知识」。
- **状态流转**：草稿 ⇄ 已定稿、资料 解析中 → 成功 / 失败、上传 → 解析 → 可引用；首页统计、课程详情计数、教案列表计数全链路联动。

## 10. 后端接口状态

后端 13 个业务接口**已全部实现**（详见 `AI-CONTEXT.md` 第 6 节），前端已在用的两个「文档未列」项也一并补齐：

真实联调前需要准备：

1. MySQL 中执行 `PrepPal/src/main/resources/db/schema.sql` 建库建表。
2. 在 `PrepPal/.env` 中配置：`DB_HOST` / `DB_PORT` / `DB_NAME` / `DB_USERNAME` / `DB_PASSWORD`、`JWT_SECRET`（**至少 32 个字符**）、`SILICONFLOW_API_KEY`、`MOCK_ENABLED=true`、`WX_APPID` / `WX_SECRET`（真实微信登录用）。
3. 启动后端：`cd PrepPal && mvnw.cmd spring-boot:run`。
4. `config/index.js` 的 `USE_MOCK` 已为 `false`，无需再改。

> 登录说明：真实微信 `jscode2session` **已接入**（后端 `UserServiceImpl.wxCodeToOpenid`）。
> - 联调阶段保持 `DEV_MOCK_LOGIN = true`，登录提交 `code=mock`，绕过真实授权；
> - 最终验收改 `DEV_MOCK_LOGIN = false` 走真实 `wx.login`，此时开发者工具必须使用真实 appid（非游客模式），否则 `code` 无效（errcode 40029/40013）。
> 真机调试时 `BASE_URL` 需改成局域网 IP 或内网穿透域名（模拟器可用 `http://localhost:8080`）。
> 可用「我的 → 开发者调试 → 后端连通性检测」验证后端是否已启动。

## 状态覆盖

- **空状态**：首页无课程、课程列表无课程、课程详情无资料/无教案、资料列表无资料、教案列表无教案（含筛选后为空）。

- **失败状态**：资料解析失败（GBK 编码原因 + 查看原因 / 重新上传）、文件超 5MB 拦截、生成超时失败（重新生成 / 返回修改）。
- **确认类**：删除资料、删除教案、删除课程、标记为定稿（“定稿后仍可再次编辑，确定标记为定稿吗？”）。
- **校验类**：课程名称必填、教学主题 / 授课对象必填、课时长 10–180 正整数，字段级红色提示 + Toast。
- **可信度提示**：有资料时显示绿色「已有 N 份资料可用于引用」；资料不足时显示黄色「以下内容基于通用知识生成，未参考到相关上传资料」，参考资料区同步切换为「通用知识」标签。
- **状态流转**：草稿 ⇄ 已定稿、资料解析中 → 成功 / 失败、上传 → 解析 → 可引用，数据全链路联动（新增课程/资料/教案会同步更新首页统计与列表）。

## 设计规范

| 令牌 | 值 |
|---|---|
| 主色（深靛蓝/智慧蓝） | `#2B4ACB`，深压 `#1B2F87`，浅底 `#EEF2FF` |
| 页面背景 | `#F3F6FC`（浅蓝灰），卡片 `#FFFFFF` |
| 成功 | `#12A150` / 底 `#E9F8EF`；警示 `#B7791F` / 底 `#FEF7E6`；危险 `#E5484D` |
| 文字 | 主 `#0F172A`、次 `#475467`、弱 `#8A94A6` |
| 圆角 | 卡片 18px、输入 14px、按钮 14px、小标签 7px |
| 阴影 | 卡片 `0 1px 2px rgba(16,24,40,.05), 0 8px 24px -14px rgba(16,24,40,.16)` |
| 字号 | 页面标题 22px、区块标题 14.5px、正文/输入 14.5px、辅助 11.5–12.5px |

小程序规范：46px 状态栏、44px 导航栏（右侧微信胶囊按钮）、底部 Tab Bar + 22px 安全区（Home Indicator）、内容区独立滚动、底部主操作条吸底且不遮挡输入。
